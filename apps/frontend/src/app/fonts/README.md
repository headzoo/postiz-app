# Plus Jakarta Sans

Self-hosted latin `.woff2` files for `next/font/local`, so production
builds do not fetch Google Fonts at compile time.

Source: [tokotype/PlusJakartaSans](https://github.com/tokotype/PlusJakartaSans)
License: SIL Open Font License 1.1 (`OFL.txt`)
Weights: 500, 600, 700 (normal and italic)
