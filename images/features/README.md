# Feature screenshots

Generated by `pnpm docs:screenshots` from `scripts/feature-screenshots.manifest.mjs`.

These committed assets are the source of truth for:

- GitHub `README.md` (`./images/features/...`)
- VitePress docs (`docs/features.md`), copied into `docs/.vitepress/static/images/features` by `pnpm docs:build:nav`

```bash
# One-time browser install after adding Playwright
pnpm exec playwright install chromium

# Frontend must be running (default http://localhost:4200)
SCREENSHOT_AUTH_TOKEN=<auth-cookie-or-jwt> pnpm docs:screenshots
```
